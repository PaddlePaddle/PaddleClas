## 1. 概述

FastViT 是一个用于图像分类任务的快速推理混合神经网络系列。它结合了卷积神经网络的效率和视觉Transformer的强大表征学习能力。该设计专注于优化推理速度，同时保持高精度，使其适用于边缘设备上的实时应用。

FastViT 通过以下几个关键创新实现了这一目标：
- **MobileOne Block**：一种可重参数化的卷积块，支持训练时的多分支架构，同时允许推理时高效的单分支执行
- **Token Mixer**：一种混合的token混合机制，结合了卷积token混合和自注意力机制，用于高效的空间信息处理
- **重参数化**：将多分支训练架构转换为单分支推理架构，以提高部署效率

参考：[FastViT: A Fast Hybrid Vision Transformer for Mobile Devices](https://arxiv.org/abs/2303.14189)
